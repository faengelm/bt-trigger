For DIY builders

Build your own BT Trigger

This page is for people who want to program and wire their own unit. If you bought a finished BT Trigger, you don't need any of this: see the user guide.

Parts

  • An original ESP32 board: "ESP32 DevKit" or "ESP32-WROOM-32" (not S3, C3 or C6).
  • A 3.5mm mono socket for the contact (or wire the contact straight to the pins).
  • Recommended: a 1 kΩ resistor in series and a 100 nF capacitor to GND, to protect the pin if something other than a passive contact gets plugged in.
  • A data USB cable and Chrome or Edge on a computer.

Wiring

  D4  ──┬──[ 1 kΩ ]──── jack tip
        │
      100 nF
        │
  GND ──┴──────────────── jack sleeve

The firmware uses D4 with the internal pull-up, active LOW, so the contact just has to connect D4 to GND. The resistor and capacitor are optional for a bench test, but worth it in a finished unit.

The status light is the board's blue LED on GPIO2: off while waiting, fast blinking when ready to pair, a short flash every 1.5 s while looking for the iPhone, steady when connected. Once it is running, holding BOOT for 5 seconds forgets all phones (holding it while powering up starts programming mode instead).

Program the board from your browser

Open this page in Chrome or Edge on a computer and plug the board in. Nothing else to install.

Use an original ESP32 board, such as an "ESP32 DevKit" or "ESP32-WROOM-32" (about $3–5). ESP32-S3, C3 and C6 won't work: their Bluetooth can't be used as a Shortcuts trigger.
This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer. Safari, Firefox and iPhone/iPad can't install it.
  1. 1

    Connect your board

    Plug the ESP32 in with a data USB cable (some cables only charge), then click Connect and pick its port.

    Port not listed / can't connect?
    • Try another cable or USB port. A charge-only cable is the #1 cause.
    • Install the USB driver for your board's chip: CP210x or CH340/CH343.
    • Hold the BOOT button, tap RESET/EN, release BOOT, then click Connect again.
    • Close other programs using the port (Arduino IDE, serial monitors, Cura…).

Questions

    
What can I connect?
      
Anything that closes two wires together without supplying power of its own: a switch, a relay contact, a reed switch on a door, a push button, or a chair or bed pressure pad. Connect it between D4 and GND.

    
Which boards work?
      
An original ESP32: boards sold as "ESP32 DevKit", "DOIT DevKit V1", "NodeMCU-32S" or "ESP32-WROOM-32", with 2 MB of flash or more.

      
ESP32-S3, C3, C6, C5 and H2 don't work. They only have Bluetooth LE, and Shortcuts doesn't offer those accessories as automation triggers. ESP32-S2 and ESP8266 have no Bluetooth.

    
Can I build from source instead?
      
Yes. The firmware is in the GitHub repository and builds with PlatformIO (pio run -e esp32). See the README for details.

    
Can I use several boards?
      
Yes. Give each one its own name: this page suggests BT Trigger 1, BT Trigger 2 and so on, counting in the browser you use. Each name gets its own automation, so each contact can run a different Shortcut.

    
Can several iPhones use one board?
      
Several iPhones can pair with it, but only one is connected at a time. The board calls the one it last connected to first.

    
How do I change the settings?
      
Plug the board in and connect it here again. Its current settings are read back. Change what you need and click Save settings only: the iPhone stays paired.

    
How do I reset it?
      
Hold the board's BOOT button for 5 seconds, or install again with "Forget paired phones" ticked. The board also gets a new Bluetooth address, so iPhones and iPads that paired before can't reconnect. Remove the old entry on the iPhone, then pair again.

    
Does it need the internet?
      
No. The board only talks to the iPhone over Bluetooth. There's no account, no app and no cloud. Whether your Shortcut uses the internet is up to you.

    
How much power does it use?
      
About 30–60 mA, so run it from a USB power supply rather than a battery.
